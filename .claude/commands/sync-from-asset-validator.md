# sync-from-asset-validator

Sync implementation from `C:\sources\asset-validator\source\python\omni\asset_validator` into this repo's `src\nvidia_usd_validation\`.

## What this does

Copies all Python source files (except `_version.py`, `__init__.py`, `__main__.py`) and applies these renames:

| From | To |
|------|----|
| `import omni.capabilities as cap` | `import nvidia_usd_validation.capabilities as cap` |
| `from omni.capabilities import` | `from nvidia_usd_validation.capabilities import` |
| `import omni.capabilities` | `import nvidia_usd_validation.capabilities` |
| `omni.capabilities.` | `nvidia_usd_validation.capabilities.` |
| `"omni.asset_validator"` (string) | `"nvidia_usd_validation"` |
| `'omni.asset_validator'` (string) | `'nvidia_usd_validation'` |
| `"omni.asset_validator:` (string prefix) | `"nvidia_usd_validation:` |
| `'omni.asset_validator:` (string prefix) | `'nvidia_usd_validation:` |
| `OMNI_ASSET_VALIDATOR_` (env var) | `NVIDIA_USD_VALIDATION_` |
| `from omni.asset_validator` | `from nvidia_usd_validation` |

Also copies:
- `tests/` subpackage (test helper mixins) → `src/nvidia_usd_validation/tests/`
- `C:\sources\asset-validator\source\python\tests\` (actual tests + data) → `tests/`
- `C:\sources\asset-validator\specs\` → `specs/`
- `C:\sources\asset-validator\source\python\docs\CHANGELOG.md` → `CHANGELOG.md` (with rename applied)

**Not copied** (intentionally):
- `_version.py` — this repo has its own static `_version.py` using `importlib.metadata`; upstream's version is a hardcoded string and must not overwrite ours
- `omni/capabilities/` — auto-generated by `repo_usd_profiles` from the specs

**Manually maintained** (not overwritten by this script):
- `src/nvidia_usd_validation/_version.py` — uses `importlib.metadata.version("nvidia-usd-validation")`
- `src/nvidia_usd_validation/__init__.py` — imports version from `_version`, all other exports from copied modules
- `src/nvidia_usd_validation/__main__.py` — keep as-is
- `pyproject.toml` — entry points and scripts already set up
- `repo.toml` — `destination_dir` already set to `${root}/src`

## Steps

1. Create a new branch: `git checkout -b feat/sync-from-asset-validator`

2. Run the migration script below in a Python shell from the repo root.

3. After the script completes, manually review and update `__init__.py` if new exports were added upstream (compare with the source `__init__.py` minus the `from ._version import` line).

4. Re-generate capabilities: `.\repo.bat usd_profiles_codegen` (Windows) or `./repo.sh usd_profiles_codegen` (Linux).

5. Run `/test` to verify the wheel builds and tests pass.

6. Commit and push, then open an MR to `main`.

## Migration script

```python
from pathlib import Path
import shutil

SRC_AV = Path("C:/sources/asset-validator/source/python/omni/asset_validator")
SRC_TESTS = Path("C:/sources/asset-validator/source/python/tests")
SRC_SPECS = Path("C:/sources/asset-validator/specs")
SRC_DOCS = Path("C:/sources/asset-validator/source/python/docs")
DST = Path("src/nvidia_usd_validation")  # relative to repo root

def transform(content: str) -> str:
    content = content.replace("import omni.capabilities as cap", "import nvidia_usd_validation.capabilities as cap")
    content = content.replace("from omni.capabilities import", "from nvidia_usd_validation.capabilities import")
    content = content.replace("import omni.capabilities\n", "import nvidia_usd_validation.capabilities\n")
    content = content.replace("omni.capabilities.", "nvidia_usd_validation.capabilities.")
    content = content.replace('"omni.asset_validator"', '"nvidia_usd_validation"')
    content = content.replace("'omni.asset_validator'", "'nvidia_usd_validation'")
    content = content.replace('"omni.asset_validator:', '"nvidia_usd_validation:')
    content = content.replace("'omni.asset_validator:", "'nvidia_usd_validation:")
    content = content.replace("OMNI_ASSET_VALIDATOR_", "NVIDIA_USD_VALIDATION_")
    content = content.replace("from omni.asset_validator", "from nvidia_usd_validation")
    # catch-all for any remaining occurrences (docstrings, log assertions, etc.)
    content = content.replace("omni.asset_validator", "nvidia_usd_validation")
    return content

SKIP = {"_version.py", "__init__.py", "__main__.py"}

# --- core source files ---
for f in sorted(SRC_AV.glob("*.py")):
    if f.name in SKIP:
        continue
    (DST / f.name).write_text(transform(f.read_text(encoding="utf-8")), encoding="utf-8")

# --- tests subpackage (helper mixins) ---
tests_sub = DST / "tests"
tests_sub.mkdir(exist_ok=True)
for f in sorted((SRC_AV / "tests").glob("*.py")):
    (tests_sub / f.name).write_text(transform(f.read_text(encoding="utf-8")), encoding="utf-8")

# --- top-level tests and data ---
tests_root = Path("tests")
for f in sorted(SRC_TESTS.glob("*.py")):
    (tests_root / f.name).write_text(transform(f.read_text(encoding="utf-8")), encoding="utf-8")
data_dst = tests_root / "data"
if data_dst.exists():
    shutil.rmtree(data_dst)
shutil.copytree(SRC_TESTS / "data", data_dst)

# --- specs ---
specs_dst = Path("specs")
for src_file in sorted(SRC_SPECS.rglob("*")):
    if src_file.is_dir():
        continue
    rel = src_file.relative_to(SRC_SPECS)
    dst_file = specs_dst / rel
    dst_file.parent.mkdir(parents=True, exist_ok=True)
    shutil.copy2(src_file, dst_file)

# --- changelog ---
changelog = (SRC_DOCS / "CHANGELOG.md").read_text(encoding="utf-8")
changelog = changelog.replace("omni.asset_validator", "nvidia_usd_validation")
Path("CHANGELOG.md").write_text(changelog, encoding="utf-8")

print("Sync complete.")
```
