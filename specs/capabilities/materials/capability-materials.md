# Visual Materials

## Overview

This capability provides requirements for the surface appearance of 3D assets, including proper material definitions, physically-based rendering of materials in visualization systems and consistent material behavior across different rendering engines.

```{note}
This capability in particular is a work in progress and will be updated over time.
```
